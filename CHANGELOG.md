### [1.1.0] - 2026-11-22

Крупное обновление установщика с улучшением безопасности, проверки окружения и восстановления после ошибок.

### Добавлено
- `--preflight`, `--plan` и `--dry-run` для предварительной проверки без изменения системы.
- Проверка REALITY-домена: DNS, TLS 1.3, X25519, HTTP/2, сертификат и безопасность адреса.
- Автоматический откат изменений и восстановление прерванной установки через `--rollback`.
- Сохранение параметров подключения и готовой ссылки `vless://`.
- Поддержка Ubuntu 22.04, 24.04 и 26.04.
- Автоматические проверки и тесты установки в GitHub Actions.

### Изменено
- Xray загружается из официального релиза с проверкой SHA256.
- Домен REALITY теперь задаётся явно через `--sni`.
- Xray запускается от отдельного пользователя с ограничениями systemd.
- Отключён журнал посещений; ошибки записываются в journald.
- Повторная установка поверх существующего Xray запрещена.
- Удаление VPN выполняется с резервным копированием конфигурации.

### Исправлено
- Совместимость с новыми форматами ключей Xray.
- Ошибки проверки портов и формирования VLESS-ссылок.
- Уязвимости и ошибки при установке, удалении и восстановлении файлов.
- Обработка прерванных операций и повторных попыток rollback.
- Проверка принадлежности системных файлов и службы Xray перед откатом.

### Проверки
- [CI Ubuntu 22.04 / 24.04 / 26.04](https://github.com/kolpakovden/mifa-vpn-basic/actions/runs/45004262794) - PASS.
- [Регрессионные проверки rollback](https://github.com/kolpakovden/mifa-vpn-basic/actions/runs/45001212778) - 20 PASS / 0 FAIL.
- [Финальный E2E с настоящим VLESS + REALITY](https://github.com/kolpakovden/mifa-vpn-basic/actions/runs/45003759931) - 23 PASS / 0 FAIL.

**Ограничения:** только чистый VPS. Проверки E2E проводились на Ubuntu 24.04 без внешнего клиентского устройства. Полная защита от конкурентных изменений привилегированным процессом и восстановление после потери питания не гарантируются.

### [1.0.0] - 2026-02-27

Первый публичный стабильный релиз MIFA VPN Basic.

- Установка Xray с VLESS + REALITY.
- Автоматическая генерация UUID и ключей REALITY.
- Настройка порта и параметров подключения.
- Поддержка неинтерактивной установки.
- Интеграция с systemd.
- Генерация готовой ссылки `vless://` для VPN-клиента.
